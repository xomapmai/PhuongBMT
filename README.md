## Bắt đầu ở đâu?
- Đọc [MASTER.md](MASTER.md) để biết mục tiêu, tiến độ, việc chờ.
- Mỗi người ghi cập nhật vào inbox của mình; khi tiến độ thay đổi đáng kể, cập nhật file vai trò.

- Xem [FILE-REGISTRY.md](FILE-REGISTRY.md) để biết chủ file và nguồn.

## Nhánh chung
`main` là nhánh chung lưu các file làm việc của cả nhóm. `MASTER.md` là bản tổng quan do Hoa quản lý.
GitHub lưu lịch sử khi có commit; không tự tổng hợp inbox vào MASTER.
Quyền theo file trong tài liệu là quy ước làm việc, chưa phải cơ chế khóa quyền GitHub.
